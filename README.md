Python Security Monitoring Project

This is my first Python cybersecurity project that I've been working on while learning the basics of programming. The program is designed to simulate login attempts and detect suspicious activity based on the number of failed attempts.

So far, I've learned how to use variables, loops, conditional statements, functions, and parameters to make the program work.

Current Features

Tracks successful and failed login attempts.

Allows the user to enter an account name.

Displays the total number of login attempts.

Generates a warning when too many failed attempts are detected.

Future Plans

As I continue learning Python, I plan to improve this project by having it analyze actual Windows Security Event Logs instead of simulated data. I would also like to eventually incorporate SQL and explore integrating it with Wazuh.

This project is still a work in progress, and I'll continue updating it as I learn more about Python and cybersecurity.
